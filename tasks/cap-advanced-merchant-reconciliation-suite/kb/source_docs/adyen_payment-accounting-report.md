# Payment accounting report

Use this report to match up fees to payment statuses and perform invoice reconciliation.

The Payment accounting report includes [Payments lifecycle](https://docs.adyen.com/reporting/reports-and-the-payments-lifecycle) status changes, events, and modifications for all transactions. You can use this report to see the costs associated with different statuses and [perform invoice reconciliation](https://docs.adyen.com/reporting/invoice-reconciliation).

**Generating and downloading**: Get this report [manually](https://docs.adyen.com/reporting/manually-get-reports) or [automatically](https://docs.adyen.com/reporting/automatically-get-reports).

**Time zone**: The [time zone setting](https://docs.adyen.com/reporting/time-zone-setting) of your account.

**Multiple reports at once**: Generate more than one Payment accounting report at a time in your [Customer Area](https://ca-test.adyen.com/).

**Availability**: Available for [company accounts](https://docs.adyen.com/account/account-structure#company-account) and [merchant accounts](https://docs.adyen.com/account/account-structure#merchant-accounts).

## Interactive payment accounting report

You can manually generate an **Interactive payment accounting** report. For each report, you can select the date range, the time zone, and the columns you want to include.

You can generate the Interactive payment accounting report using the time zone setting of your account, or Central European Time. If you want to use the report to reconcile your [payment processing invoice](https://docs.adyen.com/reporting/invoice-reconciliation/payment-processing-invoice/), select the first day of the month until the first day of the next month, select `00:00:00` for both days, and select Central European Time. This because your invoice is always based on the CET time zone.

Each report will have a unique filename. The file name and file extension depend on what you selected when you generated the report. The file name convention is:\
`payments_accounting_report_filtered_<REPORT_START_DATE>_<REPORT_END_DATE>_<UNIQUE_IDENTIFIER>`

Where:

* The default file name extension is `.csv`. We support generating reports in the file types **CSV**, **XLS\_GEN** or **TSV**.
* The date format is `YYYY_MM_DD`.
* The unique identifier is an eight-character alphanumeric string that is generated based on the date range, timezone, and events selected in the report.

The file name format of the Interactive payment accounting report has changed in February **2025**, and generating a new report no longer overwrites the previous one. If you automatically ingest report data, you may have to update your data ingestion pipeline.

Because it is interactive, this report contains different columns than the Payment accounting report. For an example, [download a sample Interactive payment accounting report](https://assets.ctfassets.net/ihg38ochctiz/27dbQwcglj2GaAEYLGXoX2/0c73a3a7660d083dbf1f84b5db8074a8/payments_accounting_report_filtered_2023_08_08_2023_08_08_09b88550.csv).

## Sample

[Download a sample Payment accounting report](https://docs.adyen.com/reporting/invoice-reconciliation/payment-accounting-report/SAMPLE_payment_accounting_report_2019_04_25.csv) for examples of the included data.

Based on your account and settings, a report you generate in your account can contain additional data or columns that are not included in the sample report.

## Report structure

### Entries

Under the header line, each line in the report is a separate entry.

### Columns

Each column shows specific information about the entries. By default, the report includes [standard columns](https://docs.adyen.com/reporting/invoice-reconciliation/payment-accounting-report#standard-columns). You can optionally add [additional columns](https://docs.adyen.com/reporting/invoice-reconciliation/payment-accounting-report#additional-columns).

## Configure report columns

If you want to add additional columns or change the order of columns in a report, you can do so in the [Customer Area](https://ca-test.adyen.com/). If you have an automated system that uses the report's data, configuring the report columns can affect your automated system.

To configure report columns, you need to have one of the following [user roles](https://docs.adyen.com/account/user-roles):

* Merchant admin
* Merchant report role
* Merchant financial
* Merchant POS Report role

To configure report columns:

1. Log in to your [Customer Area](https://ca-test.adyen.com/).
2. Go to **Settings** > **Report columns**.\
   This opens a page with all the reports that you can configure.
3. Find the report that you want to configure and select **Configure**.
4. Select checkboxes to indicate which columns you want to include in the report.
5. Drag the columns into the order you want them to appear in.
6. Select **Save configuration**.

| CloseInstallment                     | The installment will no longer be sent to the scheme and the **OpenInstallment** is closed.                                                                                                                                                                                                                                                                                                                                                                                                                         |
