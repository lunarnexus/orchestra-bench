# Settlement reconciliation

You get a settlement from Adyen when a [batch](https://docs.adyen.com/account/getting-paid#payout-batches-and-reporting) closes. Make sure that you have configured your [payout frequency](https://docs.adyen.com/account/getting-paid#payout-frequency) before performing settlement reconciliation.

These guides show you how to perform settlement reconciliation with different levels of detail.

If you are an [Adyen for Platforms](https://docs.adyen.com/?tab=adyen_for_platforms) merchant, start on the [Platform reports](https://docs.adyen.com/reporting/platform-reports) overview page instead.

###### [Transaction-level](https://docs.adyen.com/reporting/settlement-reconciliation/transaction-level)

[See each payment, refund, and chargeback included in a single payout batch and the costs for each transaction.](https://docs.adyen.com/reporting/settlement-reconciliation/transaction-level)

###### [Batch-level](https://docs.adyen.com/reporting/settlement-reconciliation/batch-level)

[See payout batches, match them to your bank statement, and see the bank/card commission costs of each batch.](https://docs.adyen.com/reporting/settlement-reconciliation/batch-level)
